# volanik #

一些程序化生成的内容。

- `main` - 程序入口
- `window` - winit 窗口管理和输入管理
- `render` - GPU 资源管理
- `skybox` - 天空盒绑定
- `scene` - 场景 uniform 管理
- `control` - 场景参数控制，相机变换
- `overlay` - egui 调试面板
- `shaders` 着色器拼接与热重载

# 操作 #

WASD 前后左右 RF 升降 QE 滚转 ZX 时间 F1 显示/隐藏调试面板

# 坐标系 & 常量 #

右手系，+z 为上，+y 为北，弧度优先。

z0 作为地表
